## I. PURPOSE

Identify **design hypotheses** to verify whether the proposed solutions truly:

- Address the right pain points of each persona.
- Create measurable value in terms of efficiency, emotion, and behavior.
- Form closed experience loops (**Planning → Exploring → Reflection → Loyalty**).

---

## II. STRUCTURE

> **Hypothesis Template**  
> We believe that [user / group]  
> need [core need]  
> because [insight or root cause].  
> We will know this is true when [measurable indicator].

### 1. PLANNING LOOP

_(Personas: Linh, Tuấn, Vy, Mai, Huy)_

| **Persona**                     | **Hypothesis Statement**                                                                                                                                                                                                     | **Expected Outcome / Metric**                                            |

| **Mai – Experienced Traveler**  | We believe that allowing experienced travelers to save and reuse old trips as templates will increase re-engagement, because it saves time and leverages trusted data.                                                       | ⤷ Trip reuse rate ≥25%<br>⤷ Returning user rate ↑                        |
| **Huy – Viewer**                | We believe that transforming shared itineraries into visual, emotional story views will improve comprehension and engagement, because the trip becomes contextual and narrative.                                             | ⤷ View-to-save conversion ↑<br>⤷ Bounce rate ↓                           |

## IV. META-HYPOTHESIS (SYSTEM LEVEL)

> If we connect the four loops — **Planning → Exploring → Reflection → Loyalty** — through a shared data ecosystem (spots, trips, emotions),  
> then the system will **self-grow in knowledge and user retention**,  
> because each loop continuously feeds content and motivation into the next.

**Validation Metrics**

- % of new trips using user-generated spots
- Retention correlation with contribution behavior
- Cross-loop conversion rate (e.g., from viewer → planner, from explorer → creator)
