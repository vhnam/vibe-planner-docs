## Persona 01 - Independent Traveler

Plans and personalizes their journey

| Attribute          | Description                                                                                                                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name**           | Linh – 29 years old, Freelancer                                                                                                                                                                                      |
| **Motivation**     | Wants to independently plan their trips, without relying on tours. Prefers finding “local” spots and having real experiences.                                                                                        |
| **Goals**          | - Create an easy trip, able to quickly add or remove spots.<br>- Save favorite spots for future trips.<br>- Get an overall view (time, cost, itinerary).                                                             |
| **Pain Points**    | - Takes 10–15 hours to gather locations from multiple sources (Google Maps, blogs, travel groups).<br>- Difficult to organize a logical travel route.<br>- Can’t remember spots they liked in previous destinations. |
| **Tech Savviness** | Average – uses phone and laptop frequently to plan, uses Google Maps, Booking, Notion.                                                                                                                               |
| **Typical Quote**  | “I don’t need a tour, I just need a smart tool to design my journey.”                                                                                                                                                |

## Persona 02 - Group Trip Planner

Organizes, creates, and shares travel plans for a group

| Attribute          | Description                                                                                                                                                                   |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name**           | Tuấn – 33 years old, Office Worker                                                                                                                                            |
| **Motivation**     | Plans trips for a group of 4–6 people, wants to save time finding locations, splitting costs, and aligning the schedule.                                                      |
| **Goals**          | - Create a shareable group plan.<br>- View an interactive map.<br>- Get spot suggestions (food, lodging, activities).                                                         |
| **Pain Points**    | - Managing a group itinerary is complex.<br>- Everyone has different preferences – hard to compromise.<br>- Uses Excel files, Google Maps separately – messy, unsynchronized. |
| **Tech Savviness** | Average – uses popular apps like Google Sheets, Telegram, Google Maps.                                                                                                        |
| **Typical Quote**  | “Planning a group trip takes more time than the actual trip.”                                                                                                                 |

## Persona 03 - Collaborator (Group Member)

Invited to participate, contribute ideas, and track the plan’s progress

| Attribute          | Description                                                                                                                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Name**           | Vy – 27 years old, Marketing Professional                                                                                                                                                                          |
| **Motivation**     | Participates in trips with friends or family, wants to contribute ideas and stay updated without being the “admin”.                                                                                                |
| **Goals**          | - Quickly view the itinerary created by friends.<br>- Add/suggest favorite spots.<br>- Know the costs, schedule, and who’s doing what.<br>- Keep conversations clear, without chat spam.                           |
| **Pain Points**    | - Needs to use multiple apps (chat, sheet, map).<br>- Doesn’t know the latest itinerary updates.<br>- Feels passive, not sure if their input is acknowledged.<br>- Often doesn’t participate due to “app fatigue”. |
| **Tech Savviness** | Average – uses Messenger, Zalo, Drive, Google Maps, Tiktok.                                                                                                                                                        |
| **Typical Quote**  | “I just want to view and suggest easily, without getting stuck in a mess of Excel and random links.”                                                                                                               |

## Persona 04 - Experienced Traveler

Advanced user, reuses itineraries and keeps detailed notes

| Attribute          | Description                                                                                                                                                                                  |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name**           | Mai – 35 years old, Travel Blogger                                                                                                                                                           |
| **Motivation**     | Keeps detailed trip notes, saves experiences for followers, manages spots for writing blogs or creating content later.                                                                       |
| **Goals**          | - Save itineraries (trip logs) that can be reused.<br>- Attach metadata to each spot (opening hours, ratings, photos, notes).<br>- Automate parts of the spot saving and organizing process. |
| **Pain Points**    | - Current apps only allow “check-ins” and don’t support notes or grouping spots by trip.<br>- Hard to manage old information.                                                                |
| **Tech Savviness** | High – uses many specialized apps (Notion, Mapstr, TripAdvisor, Google Maps).                                                                                                                |
| **Typical Quote**  | “An ideal trip planner must be both a personal notebook and an interactive map.”                                                                                                             |

## Persona 05 - Trip Viewer

Views and follows shared trip itineraries, no need for an account or complicated steps

| Attribute          | Description                                                                                                                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name**           | Huy – 31 years old, Friend of a group member                                                                                                                                                                              |
| **Motivation**     | Receives trip itinerary links from friends to see the schedule, timings, or consider joining. Doesn’t want to create an account just to view it.                                                                          |
| **Goals**          | - Quickly view trip information (timing, destinations, estimated costs).<br>- See the itinerary in one page, no need to download an app.<br>- Confirm “Join / Not Join”.                                                  |
| **Pain Points**    | - Many apps require registration before viewing.<br>- Shared links break easily or are hard to read.<br>- Doesn’t know if the itinerary is updated.<br>- Wants to view without being spammed or forced into a chat group. |
| **Tech Savviness** | Average – primarily uses phone, familiar with shared links (Google Docs, Google Maps, Facebook Event).                                                                                                                    |
| **Typical Quote**  | “I just want to click the link and see if I can join or not.”                                                                                                                                                             |
