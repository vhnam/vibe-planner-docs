## List of User Personas

### 1. Independent Traveler

Plans trips by themselves, personalizes itineraries

| Attribute            | Description                                                                                                                                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**   | Linh – 29 years old, Freelancer                                                                                                                                                                       |
| **Motivation**       | Wants to plan trips independently, without relying on tours. Likes finding “local” spots and authentic experiences.                                                                                   |
| **Goals**            | - Create trips easily, quickly add/remove spots.<br>- Save favorite spots for future trips.<br>- Have an overall view (time, cost, itinerary).                                                        |
| **Frustrations**     | - Spends 10–15 hours gathering places from various sources (Google Maps, blogs, travel groups).<br>- Difficult to organize a logical travel order.<br>- Forgets spots previously liked in past trips. |
| **Tech Proficiency** | Medium – frequently uses phone and laptop for planning, uses Google Maps, Booking, Notion.                                                                                                            |
| **Quote**            | “I don’t need a tour, I just need a smart tool that lets me design my own trip.”                                                                                                                      |

### 2. Group Planner

Organizes, creates, and shares travel plans for a group

| Attribute                         | Description                                                                                                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Age / Occupation**              | Tuấn – 33 years old, office worker, usually plans trips for 4–6 people                                                                                                                |
| **Main Behavior**                 | Uses Google Maps for reference, Excel for cost splitting, Messenger for discussion — very manual process.                                                                             |
| **Motivation**                    | - Create a visually clear plan on a map.<br>- Organize by day and by place type (food, sightseeing).<br>- Assign tasks (to-do) to each member.<br>- Avoid “everyone editing messily.” |
| **Frustrations**                  | - My Maps only allows pinning, no timeline or assignments.<br>- Cannot add “note context” (why a place was chosen).<br>- No place to track to-dos or team consensus.                  |
| **Opportunity**                   | “Tuấn needs a timeline-based trip map with tasks, allowing collaboration and clear roles among members.”                                                                              |
| **Difference from My Maps Users** | - My Maps users: only want to _illustrate a map_. <br>- Tuấn: wants to _organize a complete trip on a map_.<br>→ UX: needs an “Interactive Trip Map” instead of a “Static Map Maker.” |

### 3. Collaborator (Group Member)

Invited to join, contribute ideas, and follow the planning progress

| Attribute            | Description                                                                                                                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**   | Vy – 27 years old, Marketing Executive                                                                                                                                                                           |
| **Motivation**       | Joins trips with friends or family, wants to give input and stay updated without being an “admin.”                                                                                                               |
| **Goals**            | - Quickly view the itinerary created by friends.<br>- Add/suggest favorite spots.<br>- Know clearly costs, timing, and who’s doing what.<br>- Keep discussions clear, not spammed through chat apps.             |
| **Frustrations**     | - Has to use multiple apps (chat, sheet, map).<br>- Doesn’t know the latest version of the itinerary.<br>- Feels passive; unsure if opinions are recognized.<br>- Often disengages because “updating is tiring.” |
| **Tech Proficiency** | Medium – uses Messenger, Zalo, Drive, Google Maps, Tiktok.                                                                                                                                                       |
| **Quote**            | “I just want to view and give feedback easily, not be dragged into messy Excels and random links.”                                                                                                               |

### 4. Experienced Traveler

Advanced user, reuses itineraries and keeps detailed notes

| Attribute            | Description                                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Name (Assumed)**   | Mai – 35 years old, travel blogger                                                                                                                                 |
| **Motivation**       | Keeps detailed trip logs, stores experiences for followers, manages spots for blogging or content creation later.                                                  |
| **Goals**            | - Save reusable trip logs.<br>- Attach metadata to each spot (opening hours, rating, photo, notes).<br>- Automate parts of the spot saving and organizing process. |
| **Frustrations**     | - Current apps only support “check-in” without notes or trip grouping.<br>- Hard to manage past trip data.                                                         |
| **Tech Proficiency** | High – uses specialized apps (Notion, Mapstr, TripAdvisor, Google Maps).                                                                                           |
| **Quote**            | “An ideal trip planner should be both a personal notebook and an interactive map.”                                                                                 |

### 5. Itinerary Viewer

Views and follows shared trips, without needing an account or complex actions

| Attribute                         | Description                                                                                                                                                                            |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Age / Occupation**              | Huy – 29 years old, friend of the planner, often invited to view or join group trips                                                                                                   |
| **Main Behavior**                 | Receives a link from friends, opens map (usually My Maps or Excel), but finds it confusing or unclear what happens first or next.                                                      |
| **Motivation**                    | - Quickly see an overview of the trip, visually appealing and easy to understand.<br>- Know who’s going, when, and what the mood is.<br>- React or comment without signing up.         |
| **Frustrations**                  | - My Maps only shows pins, lacks contextual “day-by-day / story view.”<br>- Hard to understand when planner uses multiple layers.<br>- No interaction or emotional expression feature. |
| **Opportunity**                   | “Huy needs a contextual, emotional, and easy-to-understand trip map — not just random pins.”                                                                                           |
| **Difference from My Maps Users** | - My Maps users: just view raw maps.<br>- Huy: wants to see meaningful, emotional, image-rich itineraries.<br>→ UX: needs a “Trip Story View” instead of a “Pin Viewer.”               |

### 6. Spot Collector

Saves and organizes favorite spots for future trips

| Attribute            | Description                                                                                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**   | Phương – 30 years old, Designer                                                                                                                                                                   |
| **Motivation**       | Loves discovering beautiful places, unique eateries, natural attractions. Wants to save them for future trips or share with friends.                                                              |
| **Goals**            | - Quickly save spots found online or on maps.<br>- Organize spots by city or theme (e.g., “Huế – chill cafés”).<br>- Build trips from saved spots when needed.<br>- Share spot lists with others. |
| **Frustrations**     | - Saved spots scattered (Maps, Notes, IG Saves) → hard to find again.<br>- Forgets reason for saving (food? view?).<br>- No place to save metadata (opening hours, link, photo).                  |
| **Tech Proficiency** | Medium – uses social media, map apps, bookmarking tools.                                                                                                                                          |
| **Quote**            | “I haven’t gone yet, but I want to save this place for later.”                                                                                                                                    |

### 7. Place Reviewer

| Attribute            | Description                                                                                                                                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**   | Khánh – 32 years old, Communication Specialist                                                                                                                                                        |
| **Motivation**       | Likes to research thoroughly before visiting or saving spots; trusts community feedback and credible sources.                                                                                         |
| **Goals**            | - View reviews, photos, and real experiences before saving a spot.<br>- Filter spots by reliability (review count, rating, recommender).<br>- See “aggregate insights” instead of single-source info. |
| **Frustrations**     | - Has to switch between multiple apps to verify info (Maps, Tiktok, Review sites).<br>- Many fake reviews and “edited” photos.<br>- No platform aggregates reliable reviews.                          |
| **Tech Proficiency** | High – often researches across multiple sources: Google Maps, YouTube, Reddit, Instagram.                                                                                                             |
| **Quote**            | “I don’t want to save random places — only the ones truly worth visiting.”                                                                                                                            |

### 8. Local Contributor

Provides spot information, reviews, or original local content

| Attribute            | Description                                                                                                                                                                                                                        |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**   | Ngọc – 28 years old, works in the local tourism industry (tour guide / café owner)                                                                                                                                                 |
| **Motivation**       | Wants to share authentic locations, real experiences, or “local” tips to help travelers have better experiences.                                                                                                                   |
| **Goals**            | - Post new spots with accurate and up-to-date information and photos.<br>- Write useful, practical reviews.<br>- Promote local culture or activities naturally.<br>- Increase visibility or engagement for their managed location. |
| **Frustrations**     | - Large platforms (Google, TripAdvisor) are hard to access and control outdated info.<br>- Fake reviews or misinformation create bad impressions for visitors.<br>- Lacks tools to update spots quickly and easily.                |
| **Tech Proficiency** | Fairly good – familiar with social media and posting tools, but not technically advanced.                                                                                                                                          |
| **Quote**            | “I live here, I know which places are worth visiting — I just need a proper place to share them.”                                                                                                                                  |

### 9. System Curator & Verifier

Maintains data quality, verification, unification, and system suggestions

| Attribute            | Description                                                                                                                                                                                                                             |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**   | Duy – 35 years old, content manager or platform admin                                                                                                                                                                                   |
| **Motivation**       | Ensures that spot, review, and plan data are reliable, high-quality, and compliant with the system’s UX standards.                                                                                                                      |
| **Goals**            | - Moderate and verify user-submitted information before publishing.<br>- Detect duplicate reviews, incorrect or spam content.<br>- Merge duplicate spots and unify data formats.<br>- Provide “itinerary templates” to guide new users. |
| **Frustrations**     | - Crowdsourced data are error-prone and difficult to manage at scale.<br>- Too many submissions lacking clear metadata.<br>- Content management tools are still manual, lacking automation.                                             |
| **Tech Proficiency** | High – uses CMS, dashboards, and data validation tools.                                                                                                                                                                                 |
| **Quote**            | “A system is only useful when its data are trustworthy and well-structured.”                                                                                                                                                            |

### 10. Data Integrator & Source Manager

Connects and synchronizes data from official sources

| Attribute            | Description                                                                                                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Name (Assumed)**   | Quân – 34 years old, data specialist or backend developer                                                                                                                                                                |
| **Motivation**       | Ensures the system always has up-to-date spot, review, and event data from official sources (Tourism Department, VisitSingapore, Google Places, etc.).                                                                   |
| **Goals**            | - Integrate and standardize data from multiple sources.<br>- Monitor data reliability and freshness.<br>- Alert for duplicate, missing, or erroneous metadata.<br>- Support curator (Duy) in verifying and merging data. |
| **Frustrations**     | - APIs from different tourism sources are inconsistent (format, language, license).<br>- Must balance between “speed” and “accuracy.”<br>- No visual dashboard to check data quality.                                    |
| **Tech Proficiency** | Very high – understands APIs, ETL pipelines, schema validation, CMS.                                                                                                                                                     |
| **Quote**            | “If data are wrong or two months late, the user experience is ruined.”                                                                                                                                                   |

### 11. Recommendation & Data Experience Designer

Builds intelligent, emotional, and context-aware recommendation experiences

| Attribute            | Description                                                                                                                                                                                                                                                                               |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**   | Thảo – 31 years old, UX data scientist                                                                                                                                                                                                                                                    |
| **Motivation**       | Aims to help travelers receive recommendations that fit their “taste” while maintaining system reliability.                                                                                                                                                                               |
| **Goals**            | - Design recommendation mechanisms for spots/trips/stories based on user behavior and data credibility.<br>- Combine “emotion-based” data (mood, season, style) with “fact-based” data (distance, rating, time).<br>- Evaluate recommendation performance (CTR, retention, satisfaction). |
| **Frustrations**     | - Traveler behavior is unpredictable; recommendations easily biased by old data.<br>- Lacks emotional metadata (vibe, context) for AI to understand “why people like this place.”                                                                                                         |
| **Tech Proficiency** | High – skilled in UX analytics, recommender systems, A/B testing, tagging systems.                                                                                                                                                                                                        |
| **Quote**            | “Recommendations must not only be accurate, but also timely and emotionally fitting.”                                                                                                                                                                                                     |

### 12. Route Explorer

Records spontaneous routes and spots while traveling

| Attribute                         | Description                                                                                                                                                                                        |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Age / Occupation**              | Hải – 33 years old, photographer / backpacker, loves exploring and documenting real trips                                                                                                          |
| **Main Behavior**                 | Uses Google Maps or Komoot to view routes, but no app records the exact path traveled.                                                                                                             |
| **Motivation**                    | - Record real journeys via GPS, photos, or automatic logs.<br>- After trips, review and select memorable spots to save or share.<br>- Turn routes into “story maps” with emotions and real photos. |
| **Frustrations**                  | - My Maps only allows manual drawing (no tracking).<br>- Cannot attach emotions or media per point.<br>- No “record mode” to capture the real journey.                                             |
| **Opportunity**                   | “Hải needs a tool to automatically record actual routes and spots, then let him add emotions, photos, and share them as real journey stories.”                                                     |
| **Difference from My Maps Users** | - My Maps user: creates hypothetical routes before traveling.<br>- Hải: records actual routes while traveling.<br>→ UX: needs a “Route Recorder / Auto Mapper” instead of a “Draw Tool.”           |

### 13. Community Builder

| Attribute           | Description                                                                                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**  | Trang – 32 years old, travel blogger / semi-professional creator                                                                                                    |
| **Motivation**      | Wants to share real journeys, inspiring the community and building trust through authentic data.                                                                    |
| **Goals**           | - Create content from real trips (photos, routes, spots).<br>- Build credibility within the travel community.<br>- Track engagement (who views or saves her spots). |
| **Frustrations**    | - Travel platforms often don’t show real impact of contributions.<br>- Loses motivation when contributions go unrecognized.                                         |
| **Quote**           | “I don’t just travel — I want others to see that this journey is worth it.”                                                                                         |
| **Opportunity**     | “Trang needs a platform where she can share trips, see her content’s impact, and receive recognition (badges, followers, rewards).”                                 |
| **Loyalty Trigger** | Recognition + Influence.                                                                                                                                            |

### 14. Returning Traveler

| Attribute           | Description                                                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Name (Assumed)**  | Long – 30 years old, office worker, travels 3–4 times a year                                                            |
| **Motivation**      | Wants every trip (only a few per year) stored in one place, easy to revisit.                                            |
| **Goals**           | - Earn rewards for consistent use.<br>- Easily recall past trips.<br>- Feel attached because the app “understands” him. |
| **Frustrations**    | - Travel apps are often “use once then forget.”<br>- No long-term benefit for returning (no incentives).                |
| **Quote**           | “I don’t travel often, but every time I do, I use this app — because everything I need is already there.”               |
| **Opportunity**     | “Long needs a system that keeps memories, recalls them, and rewards continued use.”                                     |
| **Loyalty Trigger** | Memory + Reward (recognition / incentive).                                                                              |
