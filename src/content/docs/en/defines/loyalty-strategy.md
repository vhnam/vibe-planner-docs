## 1. Strategic Goal

> Build a **natural loyalty flywheel**,  
> where users return to the app **for emotions, memories, and community**,  
> not just for features or reward points.

Loyalty in this system is not a “reward program,”  
but a **strategy to strengthen the relationship between users and their own travel experiences.**

---

            │

 │ 💬 Social Loyalty │
 │ (Connection & discussion) │
 └──────────▲────────────────┘
            │
            │ Engagement → inspires new journeys
            ▼
 ┌───────────────────────────┐

➡️ Result: users **never leave the emotional loop**,

## 4. Four Core Loyalty Pillars

| **Loyalty Pillar**         | **Detailed Description**                                                     | **Example Product Features**                                                                                                                         |
| -------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1️⃣ Memory Loyalty**      | Preserves and replays journeys as “living experiences.”                      | - Trip Recap 360° (photos, spots, videos)<br>- “How many places have you been?”<br>- Year-in-Travel recap (Spotify Wrapped style)                    |
| **2️⃣ Recognition Loyalty** | Recognizes and honors user contributions to the community.                   | - Verified Local / Top Explorer badges<br>- Weekly Featured Route / Spot<br>- Profile “impact counter” (number of users reusing your trip)           |
| **3️⃣ Social Loyalty**      | Activates user connections and encourages authentic interaction.             | - Comment, reaction, follow traveler<br>- “Reuse from @Trang” attribution<br>- Group trip feed & discussion                                          |
| **4️⃣ Gamified Loyalty**    | Sustains behavioral motivation through levels, challenges, and soft rewards. | - Points & streak system (Spot Added, Route Shared)<br>- Level Explorer → Guide → Local Hero<br>- Seasonal Challenge (Summer Explorer, Winter Nomad) |

## 5. Loyalty Roadmap

| **Phase**                    | **Loyalty Strategy Implemented**                                                 | **UX Objective & KPI**                                             |
| ---------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **MVP (0–6 months)**         | - Basic Trip Recap<br>- Explorer Levels<br>- Simple Streak                       | Establish habit of returning (Retention D1–D7)                     |
| **Growth (6–12 months)**     | - Badge & Verified Role<br>- “Follow” & Community Feed<br>- Route Reuse tracking | Build community & boost UGC (UGC Growth +20%)                      |
| **Expansion (12–24 months)** | - Yearly Recap<br>- Seasonal Campaigns<br>- Reward for Featured Creators         | Strengthen brand & increase virality (Share Rate +30%)             |
| **Scale (24+ months)**       | - Partner Rewards (travel, brand collab)<br>- Cross-trip insights                | Expand Loyalty ecosystem with partner integration (Brand Affinity) |

## 7. Strategic Thinking vs Google Local Guide

| **Criteria**           | **Local Guide (Google)**           | **Your Application**                           |
| ---------------------- | ---------------------------------- | ---------------------------------------------- |
| **Main Objective**     | Increase map & review data         | Build personal & community travel lifecycle    |
| **Loyalty Motivation** | Points & levels                    | Memories, community & recognition              |
| **Generated Data**     | Static reviews (rating, photo)     | Living data (trip, route, spot, emotion)       |
| **User Experience**    | Transactional (“do it for points”) | Experiential (“do it because it’s meaningful”) |
| **Community**          | Anonymous, global                  | Personalized, local, travel-style based        |
| **Rewards**            | Local Guide level                  | Badge, recap, recognition, partner rewards     |
