## 1. Context Mapping Template

**Use this for quarterly Context Deep Dive:**

```markdown

### A. Market Context

- Growth rate: [%] (Target: 15-20% YoY)
- TAM/SAM/SOM: [update numbers]
- Trends: [list 3-5 key trends]
- Changes since last quarter: [what changed?]

### B. Competitive Context

- New entrants: [list]
- Giant movements: [Google, Traveloka, etc.]
- Market share shifts: [data]
- Our position: [assessment]

### C. Technology Context

- New tools/platforms available: [list]
- Cost changes: [AWS, SaaS pricing]
- Emerging trends: [AI, mobile, etc.]
- Our stack status: [assessment]

### D. Regulatory Context

- New laws/decrees: [list]
- Enforcement changes: [stricter/looser?]
- Compliance gaps: [what we need to fix]
- Risk level: [Low/Medium/High]

### E. Economic Context

- Tourism spending: [trends]
- Disposable income: [trends]
- Exchange rates: [if relevant]
- Overall sentiment: [optimistic/pessimistic]

### F. Cultural/Social Context

- User behavior shifts: [what's changing?]
- Social trends: [Gen Z preferences, etc.]
- Trust levels: [peer vs brand]
- Group dynamics: [family, friends patterns]

## 2. Internal Context

### A. Team Context

- Headcount: [current vs plan]
- Morale: [satisfaction score]
- Skills: [gaps identified]
- Capacity: [utilization %]

### B. Product Context

- Features shipped: [list]
- User metrics: [MAU, retention, etc.]
- Tech debt: [level]
- Performance: [load time, uptime]

### C. Financial Context

- Burn rate: [$/month]
- Runway: [months]
- Revenue: [MRR, growth rate]
- Unit economics: [LTV:CAC]

### D. Stakeholder Context

- User satisfaction: [NPS, satisfaction score]
- Partner satisfaction: [Partner NPS]
- Investor sentiment: [positive/neutral/negative]
- Team sentiment: [scores]

## 3. Context Impact Assessment

| Context Element | Impact on Strategy | Action Required | Priority   |
| --------------- | ------------------ | --------------- | ---------- |
| [Element 1]     | [High/Med/Low]     | [What to do]    | [P0/P1/P2] |
| [Element 2]     | ...                | ...             | ...        |

## 4. Context-Driven Decisions This Quarter

1. **Decision:** [what was decided]

   - **Context driver:** [which context element drove this]
   - **Rationale:** [why this makes sense given context]
   - **Success metric:** [how to measure]

2. [repeat for all major decisions]

## 5. Context Monitoring Plan Next Quarter

- **Watch closely:** [list top 5 context elements]
- **Review frequency:** [weekly/monthly for each]
- **Trigger for re-assessment:** [specific conditions]

## 6. Recommendation

- **Continue current strategy?** [Yes/No + why]
- **Tactical adjustments needed?** [List]
- **Pivot considerations?** [If any]
```

## 2. Context-Change Impact Matrix

**Use this to evaluate any proposed change:**

| Aspect                  | Question                                      | Answer | Implication                          |
| ----------------------- | --------------------------------------------- | ------ | ------------------------------------ |
| **Market Context**      | Does this change align with market trends?    | Yes/No | If No → Reconsider or educate market |
| **User Context**        | Does this address user pain in their context? | Yes/No | If No → Users won't adopt            |
| **Tech Context**        | Is the technology mature enough?              | Yes/No | If No → High risk                    |
| **Competitive Context** | Does this create differentiation?             | Yes/No | If No → Easy to copy                 |
| **Resource Context**    | Do we have resources (time, money, team)?     | Yes/No | If No → Deprioritize                 |
| **Cultural Context**    | Does this fit Vietnamese cultural norms?      | Yes/No | If No → Adaptation needed            |
| **Regulatory Context**  | Is this compliant with laws?                  | Yes/No | If No → Legal review first           |
| **Timing Context**      | Is NOW the right time for this change?        | Yes/No | If No → Defer to later phase         |

**Decision Rule:**

- ≥7 "Yes" → ✅ Proceed
- 5-6 "Yes" → ⚠️ Proceed with caution, mitigate Nos
- ≤4 "Yes" → ❌ Do not proceed, wrong context

| **Regulatory News** | 0 new laws | [#]    | ↗/→/↘ | 🟢/🟡/🔴 |
| **User Sentiment**  | NPS ≥40    | [#]    | ↗/→/↘ | 🟢/🟡/🔴 |
| **Team Morale**     | ≥4.0/5     | [#]    | ↗/→/↘ | 🟢/🟡/🔴 |

- 🟢 Green: All good, monitor
