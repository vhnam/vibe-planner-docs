## 4. ROI Calculator Template

```markdown
# ROI CALCULATOR - [Initiative Name]

## INPUTS

### Investment Required

| Category             | Amount   | Notes                       |
| -------------------- | -------- | --------------------------- |
| Development          | $[X]     | [X] dev-months @ $[Y]/month |
| Infrastructure       | $[X]     | Additional cloud costs      |
| Marketing            | $[X]     | Campaign costs              |
| Operations           | $[X]     | Additional support needed   |
| **TOTAL INVESTMENT** | **$[X]** |                             |

### Value Expected

| Value Stream             | Amount   | Probability | Expected Value |
| ------------------------ | -------- | ----------- | -------------- |
| User Value               | $[X]     | [%]         | $[X × P]       |
| Partner Value            | $[X]     | [%]         | $[X × P]       |
| Revenue                  | $[X]     | [%]         | $[X × P]       |
| Strategic Value          | $[X]     | [%]         | $[X × P]       |
| **TOTAL EXPECTED VALUE** | **$[X]** |             | **$[Total]**   |

### Risks

| Risk                    | Impact | Probability | Expected Loss |
| ----------------------- | ------ | ----------- | ------------- |
| [Risk 1]                | $[X]   | [%]         | $[X × P]      |
| [Risk 2]                | $[X]   | [%]         | $[X × P]      |
| **TOTAL EXPECTED LOSS** |        |             | **$[Total]**  |

## CALCULATIONS

**Expected Net Value:**

> Net Value = Expected Value - Investment - Expected Loss
> = $[X] - $[Y] - $[Z]
> = $[Result]

**ROI:**

> ROI = (Net Value / Investment) × 100%
> = ($[Net] / $[Investment]) × 100%
> = [%]

**Payback Period:**

> Payback = Investment / (Monthly Value)
> = $[Investment] / $[Monthly]
> = [X] months

## DECISION

- [ ] **APPROVE** - ROI > 100% AND Payback < 12 months
- [ ] **CONDITIONAL** - ROI 50-100% OR Payback 12-18 months
- [ ] **REJECT** - ROI < 50% OR Payback > 18 months
- [ ] **DEFER** - Good ROI but timing not right

**Justification:** [Explanation]
```
