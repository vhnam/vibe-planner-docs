## **1. PURPOSE**

Define the **scope, methods, timing, and specific objectives** of each elicitation activity to:

- Understand the needs, behaviors, and expectations of Vietnamese users in travel planning.
- Collect accurate, consistent data to form and confirm **Business, Stakeholder, and Solution Requirements**.
- Ensure the elicitation process is systematic, traceable, and verified with key stakeholders.

> 🎯 **Desired outcome:** create a sufficiently deep and reliable source of information to design accurate, feasible solutions with high business value.

---

## **2. SCOPE OF ELICITATION**

| Project Phase                        | Elicitation Objective                           | Expected Outcome                      |
| ------------------------------------ | ----------------------------------------------- | ------------------------------------- |
| **Phase 1: Discovery (0–1 month)**   | Understand user needs & behaviors               | Personas, Journey map                 |
| **Phase 2: Definition (1–2 months)** | Define functional & non-functional requirements | BRD, FRD draft                        |
| **Phase 3: Validation (2–3 months)** | Confirm solution & prototype                    | Feedback reports, Acceptance criteria |
| **Phase 4: Pre-launch (3–4 months)** | Collect insights from beta testers & partners   | Beta feedback logs, Improvement list  |

---

## **3. STAKEHOLDER TARGETS**

| Group                                        | Role in Elicitation               | Objectives to Explore               |
| -------------------------------------------- | --------------------------------- | ----------------------------------- |
| **Individual users (solo traveler)**         | Experience and planning habits    | Pain points, desired features       |
| **Friends / family groups (group traveler)** | Coordination & shared planning    | Collaboration features              |
| **Local businesses (SMEs)**                  | Promotion, customer outreach      | Business needs, trust factors       |
| **Tourism agencies (Tourism boards)**        | Destination support, visitor data | Partnership needs                   |
| **Internal development team**                | Build and operate the product     | Feasibility & technical constraints |
| **Investors / advisors**                     | Strategy guidance, ROI            | Business priorities                 |

---

## **4. ELICITATION TECHNIQUES**

| Technique Group            | Applied Methods                                                 | Objective                           |
| -------------------------- | --------------------------------------------------------------- | ----------------------------------- |
| **Qualitative**            | - In-depth interviews<br>- Contextual inquiry<br>- Focus groups | Extract real insights & pain points |
| **Quantitative**           | - Online survey (Google Form, Typeform)<br>- In-app poll        | Measure frequency & priority levels |
| **Collaborative**          | - Workshop (design sprint)<br>- Brainstorm sessions             | Co-creation                         |
| **Observation**            | - Shadowing user planning process<br>- Recording user sessions  | Validate actual behaviors           |
| **Document Analysis**      | - Facebook group posts, blog reviews, TripAdvisor data          | Identify common patterns            |
| **Prototyping & Feedback** | - Figma prototype testing<br>- Card sorting                     | Validate UI/UX concepts             |

| Phase                       | Activity                         | Objective                                   | Target Audience          | Tools               | Timeline    |

## **7. SUCCESS CRITERIA**

| Criterion                    | Description / Goal                             |
| ---------------------------- | ---------------------------------------------- |
| **Coverage**                 | ≥90% of key stakeholder groups participated    |
| **Quality**                  | ≥80% of feedback is usable or actionable       |
| **Consistency**              | No major conflicts between sources             |
| **Traceability**             | 100% requirements linked to elicitation source |
| **Timeliness**               | Completed within ≤12 weeks                     |
| **Stakeholder Satisfaction** | NPS ≥40 after workshop or interview            |

## **10. RISKS & MITIGATION**

| Risk                       | Impact                    | Mitigation                         |
| -------------------------- | ------------------------- | ---------------------------------- |
| **Low participation rate** | Insufficient sample data  | Incentives, diverse channels       |
| **Biased responses**       | Skewed insights           | Balance age & region distribution  |
| **Schedule delay**         | Elicitation timeline slip | Prepare scripts & tools in advance |
| **Inconsistent data**      | Difficult to consolidate  | Standardize data collection forms  |
| **Data privacy issues**    | Security breaches         | Obtain consent, anonymize data     |

---

## **12. SUMMARY**

> This Elicitation Plan aims for **continuous, systematic, and user-centric (User-Centric & Iterative)** processes.
> Each activity is not just about gathering information, but also an opportunity to **build trust and engage the initial user community** — a vital factor for the travel planner product.

**Three pillars of successful Elicitation:**

1. **Depth:** Thoroughly explore user behaviors & motivations.
2. **Breadth:** Ensure all stakeholder groups are represented.
3. **Validation:** Always verify insights across multiple sources before decisions.
